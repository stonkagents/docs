# Security policy

## Reporting a vulnerability

Please do not report security problems through public GitHub issues.

Email **[security@stonkagents.com](mailto:security@stonkagents.com)** with:

- what you found and where (URL, page, component)
- steps to reproduce
- what impact you believe it has

You will get an acknowledgement within three business days. We will keep you informed while we work on a fix and credit you in the release notes if you want that.

## Scope

This repository holds the documentation site for StonkAgents. Reports about the site itself (for example, a way to inject content into a page, or a build dependency with a known vulnerability) belong here.

Reports about the StonkAgents portal, the agent that runs on your machine, the tracker, or the token contracts also go to the same address; they are routed to the right team.

## Supported versions

Only the current `main` branch is maintained. There are no versioned releases of the docs.
